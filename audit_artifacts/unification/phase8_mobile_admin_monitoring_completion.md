# المرحلة 8 — توسيع لوحة الإدارة في Mobile

## النتيجة

أضيفت إلى لوحة إدارة Mobile شاشة مراقبة تشغيلية متكاملة، مساوية لسطح المراقبة في Web من حيث القراءة والتشغيل اليدوي. لا تُعرض لغير الأدمن، وتبقى حماية Backend وMFA هي سلطة الوصول الفعلية. تعرض اللوحة حالة API والبنية التحتية وملفات الفهرسة وSchema الإعلان وسجل الحالات، وتوضح إن كانت تنبيهات البريد مضبوطة.

| مجال المراقبة | مصدر البيانات | ما يعرضه Mobile |
|---|---|---|
| الحالة الأخيرة | `GET /api/admin/monitoring` | سليم / بحاجة إلى متابعة / عطل، وقت آخر فحص، وعدد الفحوص الفاشلة والتحذيرات. |
| API | `metrics.latency_ms.p95` و`metrics.errors_total` | P95 بالمللي ثانية وعدد أخطاء API، بأرقام لاتينية. |
| الاعتمادات | `latest.checks` | MongoDB وRedis وحالة API مع code وlatency والتفصيل المختصر. |
| الفهرسة | `latest.checks` | `robots.txt` و`sitemap.xml` وحالة Schema إعلان عام. |
| سجل الحوادث | `history` | أحدث عشر حالات مع الوقت والحالة وعدد الفشل/التحذير. |
| تنبيهات البريد | `email_alerts_configured` | حالة ربط Resend وبريد الأدمن دون كشف أي مفاتيح. |

## التنفيذ والأمن

يوفر `AdminMonitoringPanel.js` تحميلًا أوليًا وتحديثًا دوريًا كل 60 ثانية، وزر تحديث مباشر. زر **فحص الآن** يعرض تأكيدًا داخل التطبيق قبل استدعاء `POST /api/admin/monitoring/run`. لا يمرر المفتاح أو أي اعتماد سري إلى Mobile، ولا يمكن للواجهة تجاوز صلاحيات Router الإداري في Backend.

> الفحص اليدوي ينفذ فحوصًا محدودة للقراءة فقط ولا يعدل إعلانًا ولا يستدعي API فهرسة لمحرك بحث ولا يرسل تنبيه بريد مكرر. تستمر مهمة cron المحمية في تشغيل التنبيه البريدي عند انتقال حالة الإنتاج. [1]

عالجت المرحلة أيضًا رقمًا كان يعرض وفق locale الجهاز في بطاقات الإحصاءات الإدارية: تستعمل الآن `toLocaleString("en-US")`، فيما تستعمل لوحة المراقبة `numberingSystem: "latn"` للتاريخ والأرقام، بما يطابق قاعدة المشروع أن تكون الأرقام `0-9` في جميع اللغات.

## قيود الإطلاق

لا يمكن للسandbox اختبار لوحة مراقبة حقيقية مع هوية أدمن وبيانات إنتاج من دون تغيير بيانات أو جلسة مستخدم. قبل الإطلاق يختبر أدمن على development/production build: تحميل `GET /admin/monitoring`، رفض الحساب غير الإداري وMFA غير المكتمل، ضغط **فحص الآن** وتأكيده، ثم تحقق ظهور سجل جديد. وينبغي أيضًا التحقق من أن cron يرسل البريد عند انتقال الحالة فقط عبر بيئة اختبار آمنة.

لا تعد هذه المرحلة بتنبيه Push لحالة الإنتاج أو بمراقبة خارجية مستقلة؛ هي توحيد عملي للسطح الإداري القائم في Web وBackend إلى Mobile. لم تُغير بيانات إنتاج ولم تضف متغيرات بيئة أو مفاتيح جديدة.
