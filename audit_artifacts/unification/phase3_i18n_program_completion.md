# المرحلة 3 — برنامج التعريب وحماية النصوص غير المترجمة

## ما نُفذ

1. أضيفت مفاتيح مشتركة لوضع لغة الجهاز والعربية إلى Web وMobile.
2. أصبح اختيار اللغة في إعدادات Web وMobile يستخدم الترجمات بدل تسميات عربية صلبة.
3. أصبح زر إرسال نموذج التواصل في Web مترجمًا في حالتيه العادية والمشغولة.
4. أصبح Mobile يمرّر عناوين ومحتوى الصفحات الثابتة المعروفة عبر `t()`، مع احتفاظ عناوين البريد الخام بسلوكها الصحيح.
5. أضيف `tools/check_i18n_guard.py` لمنع إضافة نص عربي ظاهر جديد خارج `t()` أو `tr()`.
6. أضيف GitHub Actions workflow لتشغيل الحارس تلقائيًا في pull requests وعلى تغييرات `main`.

## مراجعة جرد النصوص السابق

الجرد الساكن السابق سجّل 437 مرشحًا في Web و320 مرشحًا في Mobile. لا تعني هذه الأرقام 757 خطأ ترجمة حقيقيًا؛ جزء كبير منها بيانات نطاق مثل المدن والمطارات، أو constants للمقارنة والمنطق، أو مفاتيح قاموس عربية يجب أن تبقى عربية. لذلك لا يُصلح البرنامج الآلي هذه القيم عشوائيًا.

البرنامج يحل المشكلة على مستويين:

| المستوى | النتيجة |
|---|---|
| النصوص الظاهرة ذات الأولوية | أصلحت شاشة الإعدادات والصفحات الثابتة وواجهة الإرسال، وهي أمثلة ذكرتها المراجعة. |
| منع التراجع | الحارس يمنع إضافة نص عربي مرئي جديد خارج دوال الترجمة في Web أو Mobile، مع استثناء ملفات القواميس ووسم صريح للبيانات غير المرئية. |

## قواعد استعمال الحارس

```bash
python3 tools/check_i18n_guard.py --base HEAD
```

لإضافة نص بيانات وليس نص واجهة، يجب إضافة تعليق `i18n-data` إلى السطر مع تفسير قصير. لا يجوز استخدام الاستثناء لإخفاء نص مرئي.
