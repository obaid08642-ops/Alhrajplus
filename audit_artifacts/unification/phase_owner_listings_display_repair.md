# إصلاح عرض إعلانات الملف الشخصي

**التاريخ:** 2026-08-20

## الملاحظة

كانت نقطة `/listings/me/mine` تعيد وثيقة MongoDB كاملة كما هي. يستهلك Web وMobile هذه الاستجابة مباشرة في قائمة إعلانات المالك، ما يسمح بتسرب الحقول الداخلية والمفاتيح غير المهيأة إلى واجهات لا تحتاجها ويزيد احتمال ظهور قيم غير مقروءة في قائمة الإعلانات.

## التنفيذ

تم استبدال الاستجابة الخام بعقد بطاقة مالك محدود ومهيأ. يقتصر على البيانات اللازمة للبطاقة وإجراءات الإعلان، وينظف العنوان والوصف والوسائط، ويستبعد بيانات البحث والاتصال والمراجعة الداخلية. كذلك يضيف `category_label` و`subcategory_label` و`status_label` المقروءة، مع الحفاظ على `status` كرمز تشغيل مستقل تحتاجه أزرار الإيقاف والاستئناف والترويج.

| السطح | التحديث |
|---|---|
| Backend | Projection مخصص ودالة `_owner_listing_card()` بدل إرجاع وثيقة MongoDB الخام. |
| Web | عرض اسم الفئة/الفئة الفرعية وحالة الإعلان المقروءة أسفل بطاقة الإعلان في الملف الشخصي. |
| Mobile | عرض الاسم والحالة نفسيهما في شاشة إعلاناتي، مع بقاء زر الترويج ومسار التفاصيل قابلين للاستخدام. |
