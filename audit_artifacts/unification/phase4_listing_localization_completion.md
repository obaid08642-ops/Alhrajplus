# المرحلة 4 — توحيد محتوى الإعلان متعدد اللغات

## النتيجة

أصبح **تفصيل الإعلان في Mobile** يطلب محتوى الإعلان باللغة الفعالة في التطبيق، بنفس سلوك صفحة تفاصيل الإعلان في Web. عند وجود ترجمة موثقة وحديثة للغة المطلوبة يعيد Backend حقلي `title` و`description` المترجمين؛ وعند عدم وجود ترجمة أو عند انتهاء صلاحيتها، يعيد المحتوى العربي المصدر بأمان. لا يُعرض محتوى مولّد قديم بعد تعديل الإعلان.

## ما نُفذ

| النطاق | التنفيذ |
|---|---|
| طلب Mobile | `ListingDetailScreen` يقرأ `lang` من `useI18n()` ويرسله إلى `GET /listings/{id}?lang={lang}`. |
| إعادة تحميل آمنة | تتبع شاشة التفاصيل `[id, lang]`، لذلك يعاد جلب النص المحلي عند تغيير لغة التطبيق مع الإبقاء على مسار الإعلان نفسه. |
| قياس المشاهدات | أضيف `viewedListingId` لمنع تغيير اللغة من تسجيل `listing_view` أو `POST /view` إضافيين. |
| عقد Backend | endpoint التفاصيل يعيد `seo_available_languages`، ويعيد `seo_content_language` فقط عند استخدام ترجمة موثقة وحديثة. |
| سلامة المحتوى | الترجمة الصالحة مرتبطة ببصمة `title` و`description` المصدرين؛ الترجمة التي لا تطابق البصمة لا تستخدم. |
| دورة النشر والتعديل | إنشاء إعلان مؤهل للفهرسة يشغّل توليد الترجمات في الخلفية، وتعديل `title` أو `description` يعيد التوليد ويمنع استعمال نسخة سابقة عبر البصمة. |

## ما تم التحقق منه

اختبار `backend/tests/test_phase4_listing_localization.py` يغطي الحالات الآتية:

1. طلب `lang=en` يعيد العنوان والوصف الإنجليزيين عندما تكون الترجمة حديثة.
2. طلب لغة ذات ترجمة قديمة يعيد النص العربي المصدر، ولا يصرح خطأً بأن محتوى اللغة المطلوبة عُرض.
3. `seo_available_languages` لا يسرد إلا العربية والترجمات الصالحة.
4. شفرة Mobile تحفظ تمرير `lang`، تعيد التحميل عند تغييره، وتمنع تكرار تحليلات ومشاهدات الإعلان.

## قيد اختبارات التكامل الخارجية

تمت محاولة المجموعة الكاملة عبر `pytest -q backend/tests`، لكنها تضمنت 22 ملفًا قديمًا لاختبارات تكامل HTTP تعتمد على خادم محلي أو بيئة معاينة خارجية وقاعدة بيانات/حسابات اختبار مهيأة. لم يكن أي منهما متاحًا في بيئة العمل؛ لذلك فشلت هذه المجموعة بأخطاء اتصال، لا بإخفاقات من المرحلة 4. بدلًا من تجاوز الفشل، شُغلت مجموعة الاختبارات الحتمية المعزولة أعلاه كاملة ونجحت. يلزم توفير بيئة تكامل مخصصة مع بيانات اختبار معزولة لتشغيل تلك المجموعة الخارجية بأمان؛ لم تُستخدم ولم تُعدّل بيانات الإنتاج.

## قيود معتمدة

العربية تبقى **لغة المصدر** في هذه المرحلة. لا يحاول العميل الترجمة محليًا، ولا يعرض ترجمة غير موثقة. إن لم تكتمل معالجة الخلفية بعد، يبقى النص العربي صحيحًا وقابلًا للاستخدام إلى أن تتوفر ترجمة موثقة. لا يتضمن هذا العمل أي تعديل على بيانات الإنتاج.
