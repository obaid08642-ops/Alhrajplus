# تقرير إغلاق Phase 7 — الاقتصاد والإحالات والمشاركة والترويج

**التاريخ:** 18 أغسطس 2026  
**الحالة قبل النشر:** مرشح للإغلاق؛ ستُستكمل فحوصات staging بعد دفع الـcommit ونشر Render/Vercel.

## النطاق المنفذ

تم بناء طبقة اقتصاد قائمة على **Coins فقط** للترويج، مع بقاء المحفظة النقدية منفصلة وعدم إضافة أي شحن أو مكافأة نقدية. يقرأ الخادم الإعدادات التشغيلية من مجموعة `economy_config`، مع قيم افتراضية مقيدة وحدود تحقق خادمية لمنتجات الترويج. يشمل ذلك قيمة مكافأة الترحيب والإحالة وفتح المشاركة، مفاتيح التفعيل، ومنتجات الترويج ذات `id` و`cost` و`duration_hours` و`strength`.

تم تفعيل مشاركة الإعلانات الموثقة في Web وMobile. ينشئ المستخدم المسجل share ID خادمياً قبل استخدام مشاركة النظام، ويرتبط الرابط بالإعلان والدولة والمشارك. يحمي الخادم العملية عبر نطاق الدولة، ومنع الفتح الذاتي، ومعرّف idempotency لكل زائر. لا تمنح عملية إنشاء الرابط أو النقر وحدهما مكافأة؛ تُمنح Coins للمشارك مرة واحدة فقط بعد فتح مؤهل.

تم ربط فتح رابط الإحالة في صفحة التسجيل على Web بتسجيل خادمي idempotent. يظل منح مكافأة الإحالة مؤجلاً حتى تأكيد البريد، ولا ينفذ في الواجهة. كما تم تسجيل أحداث خادمية مؤكدة للمشاركة والإحالة والترويج والـCoins في `analytics_events`، لتظهر في لوحة التحليلات الإدارية.
