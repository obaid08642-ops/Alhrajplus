# حالة الوصول إلى أدوات مشرفي البحث

**التاريخ:** 2026-08-23

تم فتح صفحة Google Search Console العامة، التي عرضت شاشة البداية وعناصر `Start now` بدل لوحة المواقع؛ لذلك لم تتوفر جلسة مالك مصادق عليها يمكن بواسطتها فحص ملكية `alhraj.online` أو إضافة sitemap. عند محاولة الانتقال إلى شاشة الدخول تغيّرت الصفحة إلى `about:blank`، فلا يمكن إتمام أي عملية في الحساب حتى يسجل المستخدم الدخول في صفحة Google المفتوحة.

لا تمثل هذه الحالة فشلًا في sitemap أو في النشر العام. التحقق الحي المستقل أكد أن `https://www.alhraj.online/sitemap.xml` متاح ويشير إلى نطاق `www` النهائي.

تم فتح صفحة مصادقة Google المباشرة لـSearch Console في 2026-08-23. الصفحة تطلب البريد الإلكتروني أو الهاتف وكلمة المرور؛ هذه البيانات لا تُدخل آليًا ولا تُطلب داخل المحادثة. يلزم أن يكمل مالك الحساب تسجيل الدخول في الصفحة المفتوحة قبل إجراء أي تحقق من الملكية أو إضافة sitemap.
