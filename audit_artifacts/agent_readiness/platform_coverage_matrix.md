# مصفوفة تغطية جاهزية الوكلاء حسب المنصة

**التاريخ:** 2026-08-23

يتناول ملف المتطلبات موارد منشورة من أصل نطاق ويب وخدمة API. لذلك لا يكون تنفيذ جميع البنود داخل تطبيق React Native صحيحًا تقنيًا؛ التطبيق لا يملك `robots.txt` أو رؤوس HTTP أصل نطاق أو مسار `/.well-known` أو واجهة `navigator.modelContext`.

| المتطلب | Web | Backend | Mobile React Native | النتيجة |
|---|---|---|---|---|
| Link headers | رؤوس الصفحة الرئيسية وصفحات الإعلان عبر Vercel | رؤوس الصفحات العامة الديناميكية | غير منطبق؛ لا يرسل التطبيق صفحات HTML | منفذ في طبقة النطاق الصحيحة |
| Markdown negotiation | Rewrite مشروط بـ`Accept` للنطاق | تمثيل Markdown للصفحة والإعلانات | غير منطبق؛ التطبيق لا يستقبل `Accept` من زائر ويب | منفذ في طبقة النطاق الصحيحة |
| Content Signals وrobots.txt | يمرر `robots.txt` | ينشئ السياسة ويحجب المسارات الخاصة | غير منطبق | منفذ في طبقة النطاق الصحيحة |
| API Catalog وPublic OpenAPI | يعرض المسارات من الدومين الأساسي | ينشئ المستندات العامة المقيدة | يستفيد من API نفسه لكنه لا ينشر الكتالوج | منفذ |
| OAuth discovery وauth.md | يمرر وثائق الاكتشاف | يصف بصدق عدم دعم OAuth grants | غير منطبق؛ ليس مصدر هوية OAuth | منفذ دون ادعاء OAuth غير موجود |
| MCP وAgent Skills وARD | نقطة اكتشاف على الدومين | MCP read-only ومهارات وmanifest | غير منطبق؛ التطبيق ليس MCP server | منفذ في Web/Backend |
| WebMCP | يسجل أداتين عامتين متى دعم المتصفح الواجهة | ينفذ الأداتين على `/api/mcp` | غير منطبق؛ `navigator.modelContext` واجهة متصفح | منفذ في Web/Backend |
| DNS-AID وDNSSEC | مستثنى بطلب المالك | مستثنى | مستثنى | لم ينفذ |

## ضمان الاتساق

يستخدم تطبيق Mobile عنوان Backend المشترك، لذلك تظل بيانات الإعلانات العامة وقواعد إخفاء البيانات الخاصة وفلتر الحالة approved/active نفسها المستخدمة في MCP وMarkdown. لا يحتاج التطبيق إلى تعديل مصدر كي لا يكرر موارد شبكة مخصصة للدومين؛ تكرارها داخل Native سيكون غير قابل للاكتشاف من محركات البحث أو الوكلاء أصلاً.
