# تكامل تطبيق Mobile مع جاهزية الوكلاء

**التاريخ:** 2026-08-23  
**النطاق:** تطبيق Expo/React Native في `mobile/`.

## ما يخص Mobile فعليًا

موارد الاكتشاف مثل `robots.txt` وLink headers وARD وAPI Catalog وWebMCP وMarkdown negotiation هي موارد HTTP للنطاق العام، ولذلك تُخدم من Web وBackend ولا يمكن لتطبيق React Native نشرها. دور Mobile الحقيقي هو استهلاك Backend نفسه، وحماية المستخدم من سلوك مضلل عندما تظهر استجابات تفويض أو دفع مستقبلًا.

تمت إضافة عقد أخطاء مركزي في `mobile/src/api.js` عبر `getApiErrorContract(error)`. يصنف هذا العقد حالات الشبكة و`401` و`403` و`402` و`422` و`429` وأخطاء الخدمة، مع `retryAfterSeconds` المقيد وخصائص مثل `requiresSignIn` و`retryable` و`paymentRequired`.

| الحالة | سلوك Mobile الآن |
|---|---|
| `401` أو Bearer challenge | يستمر refresh token الحالي لمرة واحدة؛ وإذا بقي الخطأ، تعرض شاشات الحساب رسالة جلسة/تفويض واضحة. |
| `403` | رسالة صلاحية واضحة. |
| `429` | رسالة محاولات كثيرة مع إمكانية استهلاك `Retry-After` داخليًا. |
| انقطاع الشبكة أو `5xx` | رسالة اتصال/خدمة مؤقتة قابلة لإعادة المحاولة. |
| `402` مستقبلي | حالة `paymentRequired` ورسالة محايدة فقط؛ لا URL دفع ولا provider ولا amount ولا token ولا checkout في التطبيق. |

## الشاشات الموصولة بالعقد

تم تمرير كائن الخطأ HTTP الكامل بدل `detail` فقط في شاشات تسجيل الدخول والتسجيل والتحقق MFA واستعادة/تغيير كلمة المرور، وفي تعبئة الإعلان بالذكاء الاصطناعي وتقييم ظهور الإعلان ونشر الإعلان، وفي مكافأة Coins بالمحفظة. لذلك لم تعد هذه التدفقات تفقد status أو headers قبل عرض الخطأ.

أضيفت ترجمات للرسائل الجديدة باللغات المدعومة: العربية والإنجليزية والأردية والهندية والبنغالية والفرنسية. يبقى استعمال الأرقام اللاتينية كما هو في واجهات التطبيق.

> لا يوجد OAuth agent registration أو MPP أو دفع في Mobile حاليًا، ولا ينبغي أن يضيف التطبيق شاشة دفع أو يدّعي دعمه قبل توفر endpoint حقيقي من Backend واختبار Sandbox end-to-end.

## التحقق

| الاختبار | النتيجة |
|---|---|
| `yarn test:api-contract` | نجح؛ يفحص 401 و402 و429 والشبكة وعدم عرض offer الدفع في الرسالة. |
| `npx expo export --platform android` | نجح؛ bundle Android بحجم 7.39 MB. |
| `git diff --check` | نجح قبل الرفع. |

ظهر تحذير Metro معروف من dependency متداخلة داخل `react-native-webrtc` (`event-target-shim` exports)، لكن bundling اكتمل بنجاح ولا يرتبط بعقد الأخطاء الجديد.
