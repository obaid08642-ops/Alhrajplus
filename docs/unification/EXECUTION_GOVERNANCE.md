# حوكمة تنفيذ توحيد Web وMobile

## الهدف

يوحّد هذا البرنامج القدرات والسلوك وقواعد البيانات المشتركة بين واجهة الويب والتطبيق الأصلي، مع احترام ما هو خاص بالمنصة. لا تُنسخ وظائف SEO الزاحفة إلى التطبيق؛ بل تُترجم إلى محتوى محلي وروابط عميقة وASO وقياس إحالة. ولا يُستخدم WebView داخل التطبيق بعد اجتياز مرحلة الإزالة المخصصة له.

## قواعد العمل الملزمة

| القاعدة | التطبيق العملي |
|---|---|
| مصدر حقيقة واحد | Backend وعقود API الموثقة هما مصدر البيانات والصلاحيات والحالات للقناتين. |
| عدم تعديل الإنتاج | يستخدم الاختبار حسابات وإعلانات staging فقط؛ لا يُنشأ أو يُعدل أو يُحذف سجل حي أثناء التنفيذ. |
| بوابة المرحلة | لا تنتقل أي مرحلة قبل تنفيذ بنودها، مراجعتها مقابل الخطة، وإصلاح النقص، وتشغيل اختبارات موثقة. |
| تغييرات صغيرة قابلة للعكس | تستخدم feature flags أو fallbacks لمسارات الاتصال والترجمة والواجهة عالية الخطورة. |
| أسرار خارج المستودع | لا تُسجل مفاتيح TURN أو Push أو Maps أو البريد؛ تحفظ حصريًا في متغيرات البيئة. |
| التكافؤ لا يعني النسخ الحرفي | يوحّد السلوك والبيانات، وتبقى ميزات النظام الأصلية مثل Haptics وCallKit مناسبة للتطبيق وبدائلها الصحيحة للويب. |

## مصفوفة إثبات كل ميزة

لا تُعد ميزة مكتملة إلا عندما تملك العناصر التالية:

| الحقل | الدليل المطلوب |
|---|---|
| القدرة | اسم واضح وسيناريو مستخدم أو مشرف قابل للتكرار. |
| القناتان | شاشة Web ومسار Mobile، أو تبرير مكتوب للفارق المنصّي المقصود. |
| API | endpoint وعقد request/response وصلاحية وعزل دولة إن لزم. |
| التعريب | مفاتيح اللغات الست، RTL/LTR، أرقام إنجليزية وتاريخ ميلادي. |
| الجودة | اختبارات وحدة/تكامل وE2E أو اختبار جهاز حقيقي حيث يتطلب النظام الأصلي ذلك. |
| القياس | event أو health metric يثبت أن المسار يعمل بعد النشر. |
| التراجع | كيفية إيقاف أو استعادة السلوك بلا تعديل بيانات المستخدم. |

## بوابة الاختبار القياسية

تسجل كل مرحلة في تقريرها: commit أو نطاق diff، نتائج backend وweb وmobile، حدود الاختبار غير المنفذة، وفحص `git diff --check`. لا تعتبر اختبارات API الحية أو أجهزة iOS/Android المنفذة يدويًا ناجحة إلا مع تاريخ وبيئة وحساب اختبار صريحين.

## خط الأساس

يحتفظ ملف `audit_artifacts/unification/phase1_baseline.md` بحالة الفرع، الحزمة، الاختبارات وسجل الفجوات قبل البدء. لا يُضاف أي أثر تدقيق قديم غير مرتبط إلى commits الجديدة.
